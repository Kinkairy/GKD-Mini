# Security

RC3.7 is a source snapshot for an embedded handheld system. A public firmware security review is still pending. Development/debug USB networking and recovery access must not be assumed suitable for exposure to untrusted networks.

Do not post credentials, private keys, device identifiers, personal partition contents or exploitable access details in public issues. Use GitHub private vulnerability reporting if it is enabled; otherwise ask the maintainer for a private reporting channel without including sensitive details.

This repository contains no production signing private key. A redistributable firmware release needs its own key provisioning, authentication review, clean-image validation and controlled failure/recovery testing. The project does not currently provide a supported public firmware installer.
