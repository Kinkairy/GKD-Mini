# Contributing

Please include the hardware model, version and a minimal reproduction in issues. The target is the original X1830 GKD Mini; reports for GKD Mini Plus need a separate port.

Keep system behavior in the owning module and reuse the common UI for equivalent menus, buttons, text pages, loading and result feedback. Preserve original emulator settings and make compatibility changes narrowly scoped.

For patches, describe the behavior before/after and the focused tests run. Distinguish host tests, cross-compilation and real-device acceptance. Do not include ROMs, BIOS files, OPKs, firmware images, personal saves, device identifiers or credentials. Avoid including raw private logs.

Contributions must be compatible with the applicable file/component license. Preserve upstream copyright and SPDX headers. This public repository is the reviewed publication surface; the initial source snapshot does not promise standalone firmware build support.
