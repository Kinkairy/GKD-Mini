# Changelog

## RC3.7 — portrait routing and English menu aliases

- Added trusted orientation detection for supported FBA44, FBN-ex, Handy and Oswan sessions.
- Added common portrait dot-to-Y hold autofire, release cancellation and frontend restoration.
- Made portrait button overrides configurable, including X-to-original-A for native menu confirmation.
- Added a guarded full-basename SimpleMenu alias-key patch without distributing its binary package.
- Kept the accepted hardware scope and public build limitations explicit in STATUS.

## RC3.6 — accepted F source baseline

- Published the original GKD Mini system source, kernel maintenance patches, configuration and test suites.
- Integrated application lifecycle, input routing, shared UI, rotating loading, card-state handling, USB and power management.
- Unified operation results as SUCCESS / FAILED; screenshots retain SHOT SAVED / SHOT FAILED.
- Kept one startup battery OSD and POWER LOW at 5%; retained the existing low-battery protection behavior.
- Moved system updates into settings and removed the old SYSTEM category.
- Standardized managed game-card directory names to lowercase.
- Included existing emulator repair scripts without distributing emulator packages.
- Integrated the accepted F source changes, including physical game-card lifecycle, RTC resume handling, R confirmation-page brightness and reproducible A/R image build inputs.
- Normalized public build-host paths; excluded private history, personal data, firmware and unreviewed boot artwork.

This is the public source view of RC3.7, built on the earlier RC3.6 F baseline. It is not a public firmware release or a claim of clean-card installation support.
