# Changelog

## RC3.6 — initial public source snapshot

- Published the original GKD Mini system source, kernel maintenance patches, configuration and test suites.
- Integrated application lifecycle, input routing, shared UI, rotating loading, card-state handling, USB and power management.
- Unified operation results as SUCCESS / FAILED; screenshots retain SHOT SAVED / SHOT FAILED.
- Kept one startup battery OSD and POWER LOW at 5%; retained the existing low-battery protection behavior.
- Moved system updates into settings and removed the old SYSTEM category.
- Standardized managed game-card directory names to lowercase.
- Included existing emulator repair scripts without distributing emulator packages.
- Normalized public build-host paths; excluded private history, personal data, firmware and unreviewed boot artwork.

This is a source publication of the RC3.6 feature baseline, not a new firmware release or a claim of clean-card installation support.
